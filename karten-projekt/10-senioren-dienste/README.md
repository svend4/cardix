# 10-senioren-dienste — карточки услуг для пожилых

Человек сам выбирает помощь: на бумаге, через QR у сотрудника или на своём планшете.

## Файлы
- `karten-senioren-prototyp.md` — шесть карточек, печать, порядок проверки, таблица результатов.
- `karten-senioren.html` — интерактивная страница: крупные карточки, озвучка по-немецки, офлайн. Ещё не тестировалась.

## Карточки v0
1 Einkaufen · 2 Essen · 3 Putzen · 4 Spazieren · 5 Briefe · 6 Reden.
Медицинская помощь сознательно не включена: нужны специалисты и отдельные правила.

## Принципы
- Выбор за человеком, карточка не подсказывает ответ.
- Не больше 3–4 карточек за раз при выборе на экране — проверить на людях.
- В QR только номер услуги, без данных о здоровье и имени.
- Бумажный путь всегда остаётся.

## Следующие шаги
1. Проверка на 3–5 людях, заполнить таблицу.
2. Перевести карточки в формат каталога `00-kern` (namespace `sen`).
3. HTML читает каталог из JSON, а не из встроенного списка.
4. QR уровня L2 + L1 мелко.
5. Визитка сотрудника с QR, чтобы человек видел, кто пришёл.
