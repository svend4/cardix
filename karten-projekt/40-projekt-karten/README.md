# 40-projekt-karten — карточки задач и конвейеров

## Идея
Каждая карта — одна задача или один пункт спецификации, как карточка Zettelkasten.
Карты раскладываются в конвейеры и параллельные дорожки — проектная доска без электричества.
Для обучения профессиям: необходимый порядок действий, когда прибора или алгоритма нет под рукой.

## Как ложится на ядро
- `relations.next` — порядок шагов;
- параллельные карты в одном слое — параллельный шлюз (AND), схождение — когда все готовы;
- `relations.excludes` — исключающий выбор (XOR);
- `io` — типы входа/выхода, проверка стыковки как у модулей make.com.

## Расширения (`ext.projekt`)
- `owner` — ответственный (ссылка на визитку с QR, без лишних данных);
- `done_when` — критерий готовности;
- `spec_ref` — пункт технического задания.
