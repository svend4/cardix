# 50-digitaler-zwilling — симулятор

`sim.py` — модель v0.2: заказы, робот у ячеек, курьеры, пакетирование, вызов второго курьера, сбои
(пустая ячейка, опоздание, забытый код), дождь (+40 % к поездке).

Только stdlib, Apache-2.0, работает в Termux: `python3 sim.py`.

## Важно
- Все числа — допущения. Модель полезна для сравнения вариантов, а не для прогноза.
- Каждый вариант усредняется по 40 прогонам с фиксированными seed.
- v0.1 (в чате) была ошибочной: поток заказов был больше пропускной способности, очередь росла бесконечно.
