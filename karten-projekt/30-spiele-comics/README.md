# 30-spiele-comics — игры, комиксы, слои

## Идеи
- Лист = страница комикса из нескольких карт; листы тасуются, как в таро или преферансе.
- Вход и выход на каждом листе: конвейер либо стыкуется, либо рвётся (поле `io` ядра).
- Перевёрнутый лист — обратный поток или сбой.
- Zettelwirtschaft как событие: карты теряют связи, конвейер рассыпается.
- Слои-трафареты: бутерброд (хлеб → масло → колбаса, связь `requires`), бумажная кукла
  (одежда, связь `excludes` для взаимоисключающих вещей).
- Карточный кроссворд вместо Монополии: слово = участок, пересечение с чужим словом = аренда.
- Пасьянс-режим: раздача → собрать работающий конвейер; цифровой двойник проверяет.

## Расширения ядра (`ext.game`)
- `layer` — номер слоя в стопке;
- `side` — лицо / оборот;
- `event` — карта-событие (сбой, бонус).

## Связь с другими кластерами
Карты-сбои — общий источник событий для игры и для `50-digitaler-zwilling`.
