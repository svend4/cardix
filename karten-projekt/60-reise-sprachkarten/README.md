# 60-reise-sprachkarten — разговорник для поездок

## Идея
Картинка места или действия (вокзал, аптека, вода, туалет, билет) + короткая фраза на языке страны.
Работает без сети и батареек. Карту можно просто показать человеку.

## Как ложится на ядро
- одна запись каталога, несколько языков: `ext.reise.phrases = { "de": "...", "it": "...", "ru": "..." }`;
- те же картинки, что в других кластерах: «вокзал» может быть и здесь, и в учебном цикле, и в проекте.

## Риски
- Общие карты между кластерами удобны, но путают: игровую и рабочую колоду печатать раздельно.
- Фразы проверять носителем языка.
