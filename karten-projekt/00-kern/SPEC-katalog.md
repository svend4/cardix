# Ядро: формат каталога карточек — v0.1

## 1. Модель

Каталог — один JSON-файл. Карточка — одна запись. Колода — набор номеров.
Конвейер — упорядоченный граф карточек.

```json
{
  "format": "karten-katalog",
  "version": "0.1",
  "namespace": "sen",
  "lang": "de-LS",
  "cards": [
    {
      "id": "sen-0001",
      "n": 1,
      "status": "active",
      "pic": { "emoji": "🛍️", "file": "img/einkaufen.svg", "alt": "Tasche mit Lebensmitteln" },
      "word": "Einkaufen",
      "text": "Ich brauche Einkäufe.",
      "tags": ["haushalt", "einkauf"],
      "flags": [],
      "io": { "in": [], "out": ["ware"] },
      "relations": { "next": [], "alt": [], "excludes": [], "requires": [] },
      "ext": {}
    }
  ],
  "decks": { "start": ["sen-0001", "sen-0002", "sen-0003", "sen-0004", "sen-0005", "sen-0006"] }
}
```

## 2. Поля

| Поле | Обязательно | Смысл |
|---|---|---|
| `id` | да | Глобальный ключ: `<namespace>-<4 цифры>`. Никогда не меняется и не переиспользуется. |
| `n` | да | Короткий номер для печати, крупно в углу. Уникален внутри namespace. |
| `status` | да | `active`, `draft`, `retired`. Retired-карта читается, но не предлагается. |
| `pic` | да | Картинка: emoji как запасной вариант, файл SVG как основной, `alt` для экранных чтецов. |
| `word` | да | Одно слово, 28 pt и крупнее. |
| `text` | да | Одна фраза в Leichte Sprache, одна мысль. |
| `tags` | нет | Ключевые слова (Zettelkasten-связи, поиск, фильтры). |
| `flags` | нет | Предупреждения: аллергены, «нужен специалист», «только вдвоём». Показываются всегда. |
| `io` | нет | Типы входа и выхода, как у модулей make.com. Нужны для сборки конвейеров. |
| `relations` | нет | Связи: `next` (порядок), `alt` (взаимозаменяемы), `excludes` (нельзя вместе), `requires` (нужна вместе). |
| `ext` | нет | Расширения кластеров: `ext.<кластер>.<поле>`. Ядро их не трактует. |

## 3. Правила сочетания (из BPMN)

- `next` → последовательность.
- Несколько карт без связей между собой в одном слое → **параллельно** (AND).
- `excludes` → **исключающий выбор** (XOR): кукла не может надеть два платья сразу.
- `requires` → карту нельзя положить без другой: «масло» требует «хлеб».
- Конвейер **сходится** только когда все параллельные ветки завершены.

Проверка конвейера: вход каждой карты должен совпадать с выходом предыдущей по `io`.
Несовпадение — разрыв конвейера, игровое событие «сбой».

## 4. QR и ссылки — уровни

| Уровень | Что в QR | Плюс | Минус |
|---|---|---|---|
| L0 | ничего | работает всегда | нет связи с цифрой |
| L1 | `K:sen-0001` | короткий код, офлайн-распознавание приложением | нужно своё приложение |
| L2 | `https://<домен>/k/sen-0001` | открывается любой камерой | нужен домен навсегда |
| L3 | полный JSON карты (≤ ~2 КБ) | полностью офлайн | плотный код, крупная печать |

Рекомендация: L2 с собственным доменом и таблицей перенаправлений; L1 печатать рядом мелко как запасной.
Динамические QR от сторонних сервисов — не использовать для долговечных карт.

## 5. Leichte Sprache — проверка карточки

- одно слово + одна фраза, глагол в активе;
- без отрицаний, без сокращений, без чисел в тексте;
- картинка поддерживает текст, а не украшает;
- проверено минимум на 3 людях целевой группы без подсказок.

## 6. Безопасность

- В QR только `id` карты. Никаких имён, адресов, диагнозов.
- Подмена QR наклейкой: печатать `n` и `word` крупно, приложение показывает карту и просит подтвердить.
- Подписанные коды (HMAC) — только там, где есть деньги или доступ (ячейки выдачи, `20-essen-vending`).

## 7. Версии

SemVer формата. Добавление необязательного поля — минор. Изменение смысла поля — мажор и миграция.
